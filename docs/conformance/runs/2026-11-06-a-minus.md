## 4. 剩余风险

1. **覆盖率（E1/E2）**：core/iam 缺口最大；没有达到 80/78/75 与 branch 60。不得对外宣称 A-。
2. **CI 未实跑**：所有结论来自本地等价命令；GitHub Actions 的 JDK 21、diff-cover、Testcontainers 组合尚未产生真实日志。
3. **依赖扫描（E10）**：NVD 首次同步慢且需要 API key；本地未验证，发布前必须在 CI 实跑一次。
4. **API 兼容（E9）**：基线 1.0.0 未发布；`SEEDJ_FIRST_RELEASE=true` 只对 v1.0.0 生效，之后必须解析到基线。
5. **SpotBugs 排除面**：`EI_EXPOSE_REP`/`EI_EXPOSE_REP2`/`CT_CONSTRUCTOR_THROW`/`VA_FORMAT_STRING_USES_NEWLINE` 为仓库级排除；理由已注释，但新代码的同类问题不会被规则抓住。
6. **降级开关**：`degraded-mode` 只靠显式属性，未在代码里按 profile 禁止；生产误配仍会启动。
7. **SBOM 离线陷阱**：`-o` 下 CycloneDX 静默跳过；已由 `release.sh` 硬检查拦截，但直接调用 `-Psbom` 仍会得到“成功但无制品”。
