## 5. 偏差与裁定

| 项 | 裁定 | 影响 |
|---|---|---|
| HR 样板范围 | 只实现 create/update + 时点读 + 派生字段；组织/岗位/任职/审批激活不在样板中伪造 | 规范 HR 全量用例未全部移植 |
| 条件 manifest | `IamPermissionCondition` bean；未做 manifest 解析 | 扩展清单加载留给后续 |
| Outbox 状态 | `FAILED` → `DEAD`；运维方法兼容旧 `FAILED` | 旧 SQL 若硬编码 FAILED 需同步 |
| 派生密钥 | 生产必须注入 `SEEDJ_FIELD_HASH_KEYS`；缺省测试密钥 | 部署要求已写入 README |
| 读投影剔除 | 由 `TemporalTable.writeOnlyColumns` + `ObjectQueryController` 完成 | 通用查询 API 已覆盖；浏览器读面不在本阶段 |
| 命令记录脱敏 | `CommandPayloadRedactor` 只影响落库载荷 | 事件载荷在代理侧另行剔除原始/派生值 |

## 6. 结论

L1–L4 的可执行闭环与 HR 活样板已落地；剩余工作属于扩展域（组织、岗位、任职、审批）与
部署策略（规范工具 CI、密钥托管、浏览器 BFF）。
