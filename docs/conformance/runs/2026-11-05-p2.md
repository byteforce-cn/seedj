## 3. 偏差与裁定

| 项 | 裁定 | 影响 |
|---|---|---|
| 命令业务拒绝的 HTTP 状态 | 统一 400 + `CommandRejected`（含底层 `code`），409 只用于幂等冲突 | 与冻结 `command.openapi.yaml` 一致；`EIS-409-002` 可能出现在 400 body 的 `code` 里 |
| `PENDING` 重放 | `EIS-503-001`（可重试），不返回 202 | POST 202 schema 只允许 `accepted`；崩溃遗留的 pending 命令不应被当成成功 |
| 拒绝码校验 | 用 `ContractErrorCode` 枚举白名单，不用含规范前缀的正则 | 命名门禁不误报；只接受冻结码表内的码 |
| 事件类型命名 | `CommandEvent`（`core/domain/event`），不叫 `EventEnvelope` | 避免与既有 `eventbus.EventEnvelope` 同名导入歧义；字段与 `event.schema.json` 对齐 |
| 命令代理 | `TemporalCommandAgent` 不继承 `CommandAgent` | 写入模型不同；复用 `TransactionRunner`/`LockProvider`/`Clock` 与固定顺序 |
| provider 选择 | `seedj.command.provider` / `seedj.object.provider` 缺省按依赖推断；显式 postgres 缺依赖启动失败 | 不静默降级；`TemporalCommandAutoConfigurationTest` 覆盖失败快 |
| 锁默认值 | 无 `LockProvider` 时用 `LockProvider.disabled()`，与既有 `CommandAgents` 一致 | 单实例/测试可用；多实例生产必须注入分布式锁（P2 不提供 JDBC 锁） |
| PostgreSQL 镜像 | `postgres:17-alpine`（沿用 P1） | 规范要求 16+；17 已通过 P1/P2 约束测试 |
| OpenAPI 工件 | `docs/conformance/api/` 复制规范冻结文件（v1.0.0） | 文档可对照；日常测试不依赖 Python 工具链 |
