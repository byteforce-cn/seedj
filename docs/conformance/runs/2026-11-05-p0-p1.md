## 2. 时间契约逐条对照

| 规则 | 证明 |
|---|---|
| T-R001 四时间字段必备 | `ObjectVersion` 构造期校验；`TemporalStoreContractTest.createIsVersionOneAndCurrent` |
| T-R002 半开区间 | `ObjectVersionTest.validIntervalIsHalfOpen`、`TemporalStoreContractTest.asOfUsesHalfOpenBounds` |
| T-R003 业务区间有序 | `ObjectVersionTest.rejectsInvertedOrEqualValidRange`；DDL `valid_range` |
| T-R004 系统区间有序 | `ObjectVersion` 构造期校验；DDL `recorded_range` |
| T-R005 单当前记录 | `TemporalDdlTest.rejectsSecondCurrentRow`（`uq_<table>_current`） |
| T-R006 系统时间 append-only | SPI 只暴露 `append`（封口只写 `superseded_at`），无 UPDATE/DELETE 入口；`TemporalStoreContractTest.appendSealsPreviousAndIncrementsVersion`。**已知边界**：数据库层未禁止手工改 `recorded_at`，待 P3 与审计表一起加 append-only 规则 |
| T-R007 UTC 微秒 | `ObjectVersionTest.truncatesToMicroseconds`；DDL 使用 `TIMESTAMPTZ(6)` |
| T-R008 时点单版本 | `PostgresTemporalStore` 以 `ORDER BY version DESC LIMIT 1` 收敛；`asOfUsesHalfOpenBounds` |
| T-R009 有效区间不重叠 | `TemporalDdlTest.rejectsOverlappingValidRanges`（四维 `EXCLUDE`） |
| T-R010 记录不早于发生 | 事件尚未引入（P2）；P1 不适用 |
| T-R011 迟到事实追加 | `SealingTest.lateFactAllowsHistoricalValidRangeButRejectsFuture`、`TemporalStoreContractTest.lateFactKeepsHistoryAndAllowsOverlap` |

## 3. 偏差与裁定

| 项 | 裁定 | 影响 |
|---|---|---|
| PostgreSQL 镜像 | `postgres:17-alpine` 代替 16（本地离线缓存，规范要求 16+） | 16/17 约束语义若有差异需复验 |
| 时点函数 | 不装通用 `as_of_valid(p_table, …)`（Spring 脚本切分器不认 `$$`）；改由 `TemporalDdl` 按表生成 `<table>_as_of_valid` 等 | 运维手工查询用按表函数；语义不变 |
| 创建/更正语义 | 新增 `AppendKind.CREATE`：`create` 遇已存在返回 `EIS-409-002`，`correction` 遇缺失返回 `EIS-404-001` | 调用方需按意图选工厂方法 |
| 存储事务 | `append` 不在存储层断言活动事务，要求写入 javadoc，由命令运行时保证 | 调用方漏开事务会导致封口与插入分两次提交 |
| 命名门禁 | 只匹配 token 边界（避免 `resolveIssuer` 误报）；跳过二进制资源 | 全大写后缀（如 `buildEIS`）可能漏判 |
