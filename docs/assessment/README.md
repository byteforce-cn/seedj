# 评估报告（assessment）

本目录收录针对 seedj 仓库的**阶段性评估报告**（现状盘点、缺口分析、风险清单等快照类文档）。

- **命名**：`yyyy-MM-dd-<kebab-case-title>.md`（日期在文件名，标题在文档首行）。
- **性质**：评估是**时间点的快照**；仓库演进后结论过时，应新增报告，不原地改写历史结论（勘误除外）。
- **与 ADR 的关系**：评估用于发现差距、提出候选方向；一旦形成工程决策，落为
  [`docs/adr`](../adr/README.md) 下的 ADR 进行长期追踪。
